# 다독임 미확정 요구사항 작업판

> 상태: 임시 문서
>
> 목적: 미확정 항목을 한 번에 하나씩 사용자와 결정한다. 확정된 내용은 `requirements.md`와 `decision-log.md`로 옮기고 이 목록에서 제거한다. 모든 항목이 처리되면 이 파일을 삭제한다.

## 사용 방법

1. `현재 질문` 하나만 사용자에게 묻는다.
2. 사용자가 선택하면 관련 DEC를 추가하고 확정 내용을 요구사항에 반영한다.
3. 처리한 항목을 이 파일에서 제거하고 다음 질문의 선택지만 펼친다.
4. 제외·연기한 항목도 DEC에 이유와 영향을 남긴 뒤 제거한다.
5. 질문이 모두 없어지면 이 파일을 삭제하고 요구사항 완성도 검수를 진행한다.

선택지와 추천은 Codex의 제안이며, 사용자가 답하기 전에는 요구사항이 아니다.

## 현재 질문 — `C-01` 첫 사운드 구성

C의 첫 버전에서 어떤 소리 묶음으로 시작할까요? 여기서는 소리의 **종류만** 결정하며, 실제 파일과 이용 권한은 `T-05`, `T-06`에서 별도로 확인합니다.

### 1. 균형형 5개 — 추천

- 잔잔한 빗소리
- 먼 파도 소리
- 숲의 바람 소리
- 잔잔한 시냇물 소리
- 브라운 노이즈

자연음과 일정한 노이즈를 함께 시험할 수 있어 사용자 취향과 느낌 추천 기능을 검증하기 좋습니다. 다만 처음부터 확보·검수할 파일이 5개입니다.

### 2. 자연음 중심 5개

- 잔잔한 빗소리
- 먼 파도 소리
- 숲의 바람 소리
- 잔잔한 시냇물 소리
- 조용한 밤의 풀벌레 소리

제품 분위기가 따뜻하고 자연스럽게 통일됩니다. 일정한 노이즈를 선호하는 사용자는 검증하지 못합니다.

### 3. 최소 구성 3개

- 잔잔한 빗소리
- 먼 파도 소리
- 브라운 노이즈

가장 빨리 구현하고 재생 품질을 집중해서 확인할 수 있습니다. 느낌별 추천의 다양성이 부족할 수 있습니다.
